# Esquema histórico (proyecto de Bases de Datos, curso 2022-2023)

Estos scripts SQL corresponden al proyecto de la asignatura de Bases de Datos del curso anterior, del que partió StrattonApp.
**No se usan en la aplicación actual**: el esquema real lo genera Hibernate a partir de las entidades JPA
(`Backend/src/main/java/com/StrattonApp/Backend/entities`) y difiere de estos scripts (nombres de tablas, suministros por CUPS, roles, etc.).
Se conservan únicamente como documentación de la evolución del proyecto. La auditoría técnica de 2026 está en `docs/auditoria-2026-10.md`.
